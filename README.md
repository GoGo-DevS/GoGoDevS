# GoGoDevS

Landing page profesional de una sola pagina para la marca GoGoDevS.

## Estructura

```text
GoGoDevS/
|-- index.html
|-- README.md
`-- assets/
    |-- css/
    |   `-- style.css
    |-- js/
    |   `-- main.js
    `-- img/
        `-- logo-gogodevs.png
```

## Contenido del sitio

- Hero principal con propuesta de valor de GoGoDevS.
- Seccion de servicios enfocada en paginas web, sistemas a medida y automatizacion con datos.
- Seccion de proyectos como base del portafolio.
- Seccion sobre mi para presentar el enfoque profesional de la marca.
- Seccion de contacto con acceso directo a WhatsApp y correo.

## Tecnologias

- HTML semantico
- CSS personalizado sin frameworks
- JavaScript vanilla para navegacion movil y animaciones de entrada

## Uso

1. Abre `index.html` en el navegador.
2. Reemplaza los textos de ejemplo por casos reales cuando quieras ampliar el portafolio.
3. Mantén el logo en `assets/img/logo-gogodevs.png` para que el navbar lo muestre correctamente.
